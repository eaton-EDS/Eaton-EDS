# ⚡ Cotizador EDS

Aplicación de escritorio desarrollada para facilitar y agilizar la generación de cotizaciones EDS.

<br>

## 🚀 Descarga

1. Ve a la sección **Releases**.
2. Descarga la versión más reciente del archivo `.exe`.
3. Ejecuta el archivo descargado.

> No se requiere instalación.

<br>

## ✨ Funcionalidades

✅ Generación rápida de cotizaciones  
✅ Cálculos automáticos  
✅ Interfaz simple e intuitiva  
✅ Formato estandarizado de cotizaciones  
✅ Exportación de documentos listos para compartir  

<br>

## 💻 Requisitos

- Windows 10 o superior
- Procesador de 64 bits
- Espacio disponible de 100 MB

<br>

## 🔄 Actualizaciones

Las nuevas versiones se publican mediante **GitHub Releases**.

Para actualizar:

1. Descarga la versión más reciente.
2. Reemplaza el ejecutable anterior.
3. Ejecuta la nueva versión.

<br>

## 📌 Nota

Este repositorio se utiliza únicamente para distribuir versiones ejecutables oficiales del **Cotizador EDS**.

🔒 El código fuente no se distribuye públicamente.
